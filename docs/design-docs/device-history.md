# 장치 이력 설계 조건

상태: **설계만 완료**. 이 브랜치에는 장치 이력 저장소, 차트, Eve History 서비스 또는 Matter 이력 기능을 구현하지 않았다. Homebridge의 현재 측정 서비스가 과거값 저장을 자동으로 제공한다고 가정하지 않는다.

## 목적과 데이터 경계

별도 opt-in으로 검증된 온도·습도·전력·누적 사용량·명시적으로 단위를 보정한 PM2.5의 시계열을 저장할 수 있다. 버튼 입력과 모션·문 열림 같은 이벤트는 순서·중복 특성을 모델별로 확인한 뒤 별도 이벤트 이력으로 설계한다. 장치의 목표값, IR 명령 ACK, 물리 상태가 확인되지 않은 값은 측정 이력에 섞지 않는다. 한 행은 내부 장치 ID, 측정 종류, 단위, 보정 후 수치, 실제 보고 수신 시각, 유효성·출처(realtime)를 갖는다. 원본 패킷·계정 식별자·토큰·쿠키는 저장하지 않는다. REST snapshot이나 명령의 낙관적 상태는 측정 시각이 없으므로 이력 샘플이 아니다.

## 보관·용량·삭제

제안 기본값은 장치별 최근 **30일 또는 50,000개 행 중 먼저 도달한 한계**, 저장소 전체 **64 MiB**다. 연속 수치는 값 변화 또는 1분 경과 시만 추가해 같은 값의 대량 중복을 줄인다. 이벤트형 데이터에는 1분 샘플링을 적용하지 않으며 별도 한도를 둔다. 한계 도달 시 오래된 행부터 제거하고 삭제된 수와 마지막 정리 시각을 진단에 남긴다. 쓸 수 없는 디스크, 용량 초과 또는 쓰기 대기열 1,000건 초과 때는 장치 제어를 막지 않고 신규 이력만 건너뛰며 누락 건수를 기록한다. 이러한 숫자는 실사용 데이터량 측정 전의 설계 기본값이다.

사용자가 설정 화면에서 이력을 끄거나 삭제를 요청하면 해당 계정의 이력 파일을 명시적으로 지운다. 세션의 계정 소유자가 바뀌거나 로그아웃하면 이전 계정의 이력을 새 계정에 보여주지 않고 지운다. 같은 계정의 토큰만 갱신될 때는 계정 ID를 비밀값 없이 안정적으로 판정할 수 있는 별도 계약이 필요하다. 현재 token 기반 `sessionFingerprint`는 토큰 갱신에도 바뀌므로 이를 단독 계정 ID로 사용하면 이력이 불필요하게 삭제된다. 장치 제거는 7일 유예 후 정리하되 그 사이 UI에는 표시하지 않는다. 수동 내보내기를 도입한다면 비식별화, 단위·시간대 표기와 사용자 지정 경로 저장을 별도 기능으로 검증한다.

## 저장소·복구 계약

프로세스와 UI 간에는 버전이 있는 읽기 전용 조회 API를 두고, 저장소는 Homebridge 전용 0700 디렉터리의 0600 파일에 둔다. 한 프로세스만 쓰고, 샘플 추가·오래된 행 제거는 트랜잭션으로 처리한다. 전원 단절 후 무결성 검사, 손상 시 원본 보존·새 DB 시작, 스키마 버전 마이그레이션과 백업/복원을 테스트한다. 기록 순서는 공급자 이벤트 시각이 신뢰될 때만 그 값을 따르고, 없거나 단위가 불명확하면 로컬 수신 시각과 `timestampSource`를 저장한다. 세션 교체 중 늦게 온 이전 계정 샘플은 generation/owner gate에서 버린다.

## 표시 프로토콜과 라이브러리 선정 게이트

첫 단계는 플러그인 UI의 로컬 차트로 한정하고, HAP/Eve 전용 history 또는 Matter history는 별도 선택 기능으로 다룬다. 구현 라이브러리는 유지보수 상태, Node 22/24/26과 Homebridge 2.4 지원, macOS/Linux 설치·패키징, 원자적 쓰기·잠금·마이그레이션, 읽기 전용 UI 조회, 무네트워크 동작을 모두 확인한 뒤 선택한다. native SQLite 바인딩을 쓰면 각 Node ABI/플랫폼의 prebuild와 소스 빌드 회귀가 필수다. `node:sqlite` 또는 순수 JS/WASM 대안은 지원 Node 최소 버전에서 안정성·성능·복구 증거를 비교해야 한다. Eve 연동은 실제 Eve 앱의 서비스·단위·재시작 복원 및 라이브러리 유지보수를 검증하기 전까지 제공하지 않는다. Matter에도 일반적인 과거 차트 기능이 있다고 표시하지 않는다.

## 완료 증거

구현을 시작할 때는 최소 두 종류의 실제 센서와 계측 플러그에서 30일 보관·64 MiB 제한, 결측·오래된 값 미기록, 계정 교체/로그아웃 삭제, 비밀정보 부재, 재시작·디스크 부족·DB 손상 복구, Node/OS 조합, 내보내기 재열기까지 검증해야 한다. Eve/Matter 확장은 별도 컨트롤러 실기 증거가 있어야 완료 표시한다.
