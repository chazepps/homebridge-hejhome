# Hejhome 3.1 설치·시험·이전 버전 복귀 안내

대상: 정식 **3.1.0**, npm **`latest`** 채널. 기존 3.1 베타의 기능이 정식에 포함됐습니다.

## 설치

Homebridge 2.4 이상, 관리 화면 5.29 이상, Node 22.13 이상인 22.x 또는 24.x·26.x를 사용합니다. Homebridge 자체를 베타로 바꿀 필요는 없습니다.

Homebridge 관리 화면에서 Hejhome 플러그인을 설치하거나 업데이트합니다. 3.1 베타를 사용 중이라면 버전 선택에서 **3.1.0**을 선택합니다. 설치 전 Homebridge 설정과 저장 공간을 보존하세요.

## 새 기능

- **헤이홈 레시피:** 헤이홈 앱에서 만든 레시피를 **연결 → 헤이홈 레시피**에서 켭니다. 저장 후 브릿지를 재시작하면 HomeKit·Matter에 일회 실행 스위치가 추가됩니다. Matter에서는 실행 완료 후 약 1초 뒤 꺼집니다. 레시피 안의 기기 상태를 표시하지 않으며, 헤이홈 앱의 레시피는 변경하지 않습니다.
- **TV·셋톱박스 즐겨찾기 채널:** 장치 설정에서 최대 8개, 이름과 채널 번호 0–999를 지정합니다. Apple Home 순간 버튼이 한 번 명령을 보냅니다. 기존 항목 수정 시 식별자는 유지하며, 삭제 후 재등록은 새 버튼입니다.
- **공기청정기 모드 버튼:** 지원 타입 `Airpurifier`에 자동·수동·취침 요청 버튼을 추가합니다. 실제 운전 상태를 추정하지 않습니다.
- **포트별 이름:** 다구 스위치·멀티탭의 제어 포트 이름을 지정합니다. 비우면 기본 이름을 사용하며 HAP subtype·Matter part ID를 유지합니다. 컨트롤러에서 직접 지정한 이름이 우선할 수 있습니다.

장치별 설정은 **장치 → 장치 선택 → 설정**에서 저장하고 Homebridge를 다시 시작합니다. 즐겨찾기·공기청정기 모드 버튼은 Apple Home(HAP) 연결에서만 나타나며 Matter 전용·숨김에서는 설정만 보관합니다. 레시피 스위치는 HomeKit과 Matter를 지원합니다. 모두 기본적으로 비활성 또는 미설정입니다.

## 시험 범위

설정 저장·삭제, 반복 버튼 입력, 실패 전파, 계정 교체 경합, 캐시 복원과 식별자 유지, 비동기 제거·재등록을 자동 테스트로 확인합니다. 실제 기기 동작과 컨트롤러별 표시·이름 반영은 실기 검증 대상입니다. 명령 전송 성공은 실제 동작 확인과 구분합니다.

## 3.0.6으로 복귀

3.1에서 레시피와 추가 버튼을 끄고 즐겨찾기·포트 이름을 비운 뒤 저장·재시작합니다. 직접 설정을 편집한다면 **`features.scenes`**와 `features.devices` 각 장치의 **`favoriteChannels`·`purifierModeButtons`·`channelNames` 키를 삭제**하고 JSON을 저장하세요. 이전 버전은 이 키를 알지 못하므로 남겨 두면 설정 검증에서 시작이 거부될 수 있습니다.

Homebridge 관리 화면의 버전 선택에서 **3.0.6**을 설치하고 재시작합니다. 기존 계정·장치의 페어링 정보를 초기화할 필요는 없습니다. 3.1에서 추가한 스위치를 사용하는 Home 자동화는 제거·재설정이 필요할 수 있습니다.

## English

Install stable **3.1.0** from npm **`latest`**, or select it explicitly when moving from the 3.1 beta. Enable recipes under **Connections → Hejhome recipes**, save and restart the bridge. Recipe switches support HomeKit and Matter; Matter returns them to off about one second after execution finishes. Favorites and purifier-mode buttons remain Apple Home(HAP) features. Port names preserve service and endpoint identities. Real-device operation and controller-specific display still require physical testing.

Before downgrading to 3.0.6, disable recipes and additional buttons, clear favorites and port names, then save and restart 3.1. If editing JSON directly, remove **`features.scenes`** and **`favoriteChannels`, `purifierModeButtons`, `channelNames`** from each entry under `features.devices`. Install 3.0.6 and restart; preserve existing pairing data.
