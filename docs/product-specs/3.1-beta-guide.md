# Hejhome 3.1 베타 설치·시험·복귀 안내

대상: **3.1.0-beta.1**, npm **`beta`** 채널. 정식 `latest`는 **3.0.6**으로 유지합니다.

## 설치

Homebridge 2.4 이상, 관리 화면 5.29 이상, Node 22.13 이상인 22.x 또는 24.x·26.x를 사용합니다. Homebridge 자체를 베타로 바꿀 필요는 없습니다.

Homebridge 관리 화면에서 Hejhome 플러그인의 **이전 버전 설치**(화면에 따라 다른 버전 설치)를 열고 **3.1.0-beta.1**을 직접 선택합니다. 설치 전 Homebridge 설정과 저장 공간을 보존하세요. 일반 업데이트는 `latest`의 정식을 사용합니다.

## 새 기능

- **TV·셋톱박스 즐겨찾기 채널:** 장치 설정에서 최대 8개, 이름과 채널 번호 0–999를 지정합니다. Apple Home 순간 버튼이 한 번 명령을 보냅니다. 기존 항목 수정 시 식별자는 유지하며, 삭제 후 재등록은 새 버튼입니다.
- **공기청정기 모드 버튼:** 지원 타입 `Airpurifier`에 자동·수동·취침 요청 버튼을 추가합니다. 실제 운전 상태를 추정하지 않습니다.
- **포트별 이름:** 다구 스위치·멀티탭의 제어 포트 이름을 지정합니다. 비우면 기본 이름을 사용하며 HAP subtype·Matter part ID를 유지합니다. 컨트롤러에서 직접 지정한 이름이 우선할 수 있습니다.

**장치 → 장치 선택 → 설정**에서 저장하고 Homebridge를 다시 시작합니다. 추가 버튼은 Apple Home 연결에서만 나타나며 Matter 전용·숨김에서는 설정만 보관합니다. 모두 기본적으로 비활성 또는 미설정입니다.

## 시험 범위

설정 저장·삭제, 반복 버튼 입력, 실패 전파, 캐시 복원과 식별자 유지, 장치 종류 변경 후 부적합 설정 제거를 자동 테스트로 확인합니다. 실제 TV·청정기의 동작과 Apple Home·기타 Matter 컨트롤러의 사용자 지정 이름 우선순위는 실기 검증 대상입니다. 명령 전송 성공은 실제 동작 확인과 구분합니다.

## 3.0.6으로 복귀

베타에서 추가한 버튼을 끄고 즐겨찾기·포트 이름을 비운 뒤 저장합니다. 직접 설정을 편집한다면 `features.devices`의 각 장치에서 **`favoriteChannels`·`purifierModeButtons`·`channelNames` 키를 삭제**하고 JSON을 저장하세요. 이전 버전은 이 키를 알지 못하므로 남겨 두면 설정 검증에서 시작이 거부될 수 있습니다.

Homebridge 관리 화면의 버전 선택에서 **3.0.6**을 설치하고 재시작합니다. 기존 계정·장치의 페어링 정보를 초기화할 필요는 없습니다. 베타에서 새로 추가한 버튼을 사용하는 Home 자동화는 제거·재설정이 필요할 수 있습니다.

## English

Choose **3.1.0-beta.1** explicitly using Homebridge UI's alternate-version picker. Stable `latest` stays on **3.0.6**. Favorites and purifier modes are momentary Apple Home buttons; port names preserve service and endpoint identities. Save settings and restart Homebridge. Physical device operation and controller-specific naming precedence still require real-device testing.

Before downgrading to 3.0.6, clear favorites, disable purifier mode buttons and clear port names in the beta UI, then save. If editing JSON directly, remove **`favoriteChannels`, `purifierModeButtons` and `channelNames`** from every entry under `features.devices`. These keys are unknown to 3.0.6 and can prevent startup if retained. Install 3.0.6 and restart; preserve existing pairing data.
