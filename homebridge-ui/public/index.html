for Homebridge

앱스토어나 플레이스토어에서 헤이홈 어플을 다운 받아 구체적인 설정을 먼저 마친 뒤, 헤이홈 앱에 등록한 이메일로 로그인해 주세요.

로그인 정보와 장치의 최근 상태, 문제 확인용 기록은 이 Homebridge에 저장해요. 비밀번호는 저장하지 않고 개발자에게 자동 전송하지 않아요.

업그레이드 안내: v1에서 v2로 업그레이드되면서 변화가 많습니다. 문제가 있다면 Homebridge 플러그인 메뉴에서 액세서리 초기화를 실행한 뒤 다시 로그인해 주세요.

Hejhome 설정

Hejhome Web 로그인 정보를 Homebridge 저장 공간에 보관하고, 발견한 장비를 Home 앱에 보여줍니다.

첫 번째 집

처음 로그인하면 첫 번째 집의 모든 방을 사용합니다. 여기서 언제든 바꿀 수 있습니다.

2.1 베타 기능

선택 사용

설정을 저장한 뒤 Homebridge를 다시 시작해 주세요.

Google Home·SmartThings 등에서 사용할 장치를 Matter로 노출합니다. Homebridge의 해당 브리지에서도 Matter를 켜고 표시된 QR로 연결해 주세요. 이미 HomeKit에 연결된 장치를 같은 앱에 다시 연결하면 중복 표시될 수 있습니다.

지원하는 조명에 Apple Home의 시간대별 자동 조명을 제공합니다. Home 앱에서도 적응형 조명을 켜야 합니다. 클라우드에 주기적으로 명령을 전송합니다.

고급: 전력 측정 모델 설정

확인된 모델명과 원본 필드의 단위 배율만 입력하세요. power는 W, current는 A, voltage는 V, energy는 누적 Wh 기준입니다. 측정되지 않은 값은 추정하지 않습니다.
