3.0 베타 기능

선택 사용

설정을 저장한 뒤 Homebridge를 다시 시작해 주세요.

Google Home·SmartThings 등에서 사용할 장치를 Matter로 노출합니다. Homebridge의 해당 브리지에서도 Matter를 켜고 표시된 QR로 연결해 주세요. 이미 HomeKit에 연결된 장치를 같은 앱에 다시 연결하면 중복 표시될 수 있습니다.

지원하는 조명에 Apple Home의 시간대별 자동 조명을 제공합니다. Home 앱에서도 적응형 조명을 켜야 합니다. 클라우드에 주기적으로 명령을 전송합니다.

고급: 전력 측정 모델 설정

첫 줄은 실제 장치값이 아닌 가상 참고 예시이며 저장되지 않습니다.

표를 좌우로 밀거나 표에 초점을 둔 뒤 화살표 키로 이동해 나머지 항목을 확인하세요.

모델측정 종류 계산용 숫자배율 변환 결과 삭제
모델
내 장치에서 모델명을 선택하거나 직접 입력하세요. 선택만으로 측정 기능이나 단위가 확인되지는 않습니다.
측정 종류
전력·전압·전류·누적 사용량 중 하나를 선택하세요. 종류를 선택할 때만 기본 원본 항목이 정해집니다.
계산용 숫자
계산해 볼 숫자를 직접 입력하세요. 실제 장치값을 자동으로 읽지 않으며 저장하지 않습니다.
배율
원본 숫자에 곱해 W·V·A·Wh로 바꾸는 값입니다. 모델의 원본 단위를 확인한 뒤 입력하세요.
변환 결과
계산용 숫자 × 배율의 미리보기입니다. 결과도 저장되지 않습니다.
측정 행 삭제
이 행의 측정 설정만 삭제합니다. 같은 모델의 다른 측정 종류는 유지됩니다.
전문가용 원본 설정

기본 원본 항목은 전력 curPower, 전압 curVoltage, 전류 curCurrent, 누적 사용량 totalWh입니다. 기존 사용자 지정 항목은 아래 원본 설정에서 유지·수정할 수 있습니다.

원본을 편집하는 동안 표 입력을 잠갔습니다. 표에서 계속 편집하려면 원본을 표에 적용하세요.
