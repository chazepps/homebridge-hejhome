헤이홈 앱에 등록한 조명·스위치·플러그·센서를 Apple Home에서 사용하고, Siri와 홈 앱 자동화에 연결할 수 있습니다. 지원 기기는 Matter를 통해 Google Home·SmartThings에도 연결할 수 있습니다.

헤이홈 계정과 인터넷 연결이 필요하며, 기기 제어에는 헤이홈 클라우드를 사용합니다.

> **3.0 베타 안내**
> 이 문서는 개발 중인 **3.0.0-beta.1** 기준입니다. 해당 버전은 아직 npm에 게시하지 않았으며, 공개된 정식 버전과 기능·실행 환경이 다를 수 있습니다. 베타가 게시되면 사용자가 직접 선택해 설치해야 합니다.

## 주요 기능

- **필요한 장치만 연결** — 사용할 집·방과 장치별 연결 방식을 선택합니다.
- **한곳에서 설정** — 장치·연결·전력·도움말 메뉴를 제공합니다. 한영, 밝은 테마·어두운 테마, 모바일 화면을 지원합니다.
- **새 장치 자동 검색** — 새 상태 알림과 주기적인 목록 조회로 추가된 장치를 찾습니다.
- **입력 내용 보존** — 메뉴 이동과 상태 갱신 중에도 작성 중인 설정을 유지합니다.
- **상태와 결과 구분** — 장치의 보고값, 연결 준비 상태와 명령 전송 결과를 구분해 표시합니다.

## 시작하기

### 1. 실행 환경 확인

| 항목 | 3.0 베타 요구사항 |
| --- | --- |
| Homebridge | 2.4 이상인 2.x 계열 |
| Homebridge 관리 화면 | 5.29 이상 |
| Node.js | 22.x는 22.13.0 이상, 또는 24.x·26.x |
| 헤이홈 계정 | 이메일 로그인과 앱에 등록된 장치 |
| 네트워크 | 헤이홈 클라우드 접속. Matter 사용 시 같은 네트워크에서 IPv6·mDNS 동작 필요 |

Homebridge 자체를 베타로 바꾸거나 관리 화면의 알파 버전을 설치할 필요는 없습니다.

설정 화면의 리모컨·에어컨·공기청정기 조작은 **Homebridge 서버가 macOS/Linux에서 실행될 때** 사용할 수 있습니다. Windows 서버에서는 이 조작을 제공하지 않습니다. 브라우저를 여는 기기의 운영체제, 설정 편집과 Apple Home/Matter의 조작 경로는 이 제한과 별개입니다.

### 2. 플러그인 설치

Homebridge 관리 화면의 **플러그인** 메뉴에서 `@chazepps/homebridge-hejhome`을 찾아 설치합니다. 명령어를 사용할 때는 Homebridge가 설치된 환경에서 실행하세요.

```sh
# 공개된 정식 버전 설치
npm install -g @chazepps/homebridge-hejhome@latest
```

**3.0.0-beta.1은 게시 후에 다음 명령으로 설치할 수 있습니다.**

```sh
npm install -g @chazepps/homebridge-hejhome@3.0.0-beta.1
```

게시된 베타를 선택할 때는 `@beta`도 사용할 수 있습니다. 태그가 없으면 설치가 실패하고, 다른 베타를 가리키면 그 버전이 설치됩니다. 먼저 채널과 버전을 확인하세요.

```sh
npm view @chazepps/homebridge-hejhome dist-tags
npm install -g @chazepps/homebridge-hejhome@beta
```

### 3. 로그인하고 장치 선택

1. Hejhome 플러그인의 설정 화면을 엽니다.
2. 헤이홈 계정의 이메일로 인증번호를 받고 인증합니다.
3. 비밀번호로 로그인합니다. 비밀번호와 인증번호는 저장하지 않습니다.
4. **연결 → 집과 방**에서 사용할 공간을 선택합니다. 기본값은 첫 번째 집의 모든 방입니다.
5. **집/방 설정 저장**을 누르고 재시작 안내를 따릅니다.

하나의 Homebridge 저장 공간에서는 **헤이홈 계정 하나**를 사용합니다. 같은 계정의 여러 집·방은 선택할 수 있지만 여러 계정을 동시에 연결하는 기능은 아직 없습니다. 다른 계정으로 로그인하면 기존 로그인 세션이 교체됩니다.

직접 `config.json`을 편집한다면 최소 설정은 다음과 같습니다. 로그인은 설정 화면에서 별도로 진행합니다.

```json
{
  "platform": "Hejhome",
  "name": "Hejhome"
}
```

## 설정 화면

| 메뉴 | 주요 기능 |
| --- | --- |
| **장치** | 이름·종류·모델 검색, 표시 이름·연결 방식 설정, 지원하는 장치 조작 |
| **연결** | 계정 상태·재로그인, 집·방 선택, Matter·적응형 조명 설정 |
| **전력** | 소비전력·대기전력 입력, 실제 전력 측정 모델의 고급 설정 |
| **도움말** | 연결 상태, 개인 정보 없는 진단, 베타 안내, 모델별 지원 범위 |

변경한 내용은 각 영역의 저장 버튼으로 저장합니다. 재시작이 필요한 설정은 화면에 안내합니다. **‘준비됨’은 Homebridge가 연결을 준비했다는 뜻이며, Apple Home 페어링 완료를 확인한 표시는 아닙니다.**

### 다른 스마트홈 앱에 연결하기

Matter는 기본적으로 꺼져 있습니다. **연결 → Matter 연결**을 켜고, Homebridge의 해당 브리지에서도 Matter를 켭니다. 이후 연결할 앱에서 브리지의 Matter QR을 사용하세요. 같은 앱에 같은 장치를 Apple Home 연결과 Matter 연결로 모두 추가하면 중복 표시될 수 있습니다.

Matter를 사용해도 헤이홈 클라우드는 계속 필요합니다. 기기에 로컬 통신이나 Thread 기능이 추가되지는 않습니다. Homebridge의 Matter는 커뮤니티 구현이며 인증된 상용 Matter 제품은 아닙니다.

### 새 장치 자동 찾기

새 장치의 상태 알림을 받으면 서버 목록을 다시 확인합니다. **현재 계정과 선택한 집·방에 속하는 지원 장치**만 기존 표시 설정에 따라 추가합니다.

후속 알림 검색은 최소 30초 간격으로 실행하며, 조회해도 찾지 못한 ID의 같은 알림은 5분간 반복 검색하지 않습니다. 알림이 없어도 기본 5분 주기로 목록을 확인합니다. 조회 실패 시 기존 장치를 유지하고 다시 시도하므로 실제 반영 시간은 더 길어질 수 있습니다. 아직 지원하지 않는 모델의 기능이 자동으로 추가되는 것은 아닙니다.

### 조명 색 자동 조절

지원하는 색온도 조명에서 **연결 → 적응형 조명**을 켜고, Apple Home에서도 적응형 조명을 선택합니다. 시간대에 따라 색온도를 바꾸며 클라우드에 주기적으로 명령을 보냅니다. 기본값은 꺼짐입니다.

### 소비전력과 전력량

**전력** 메뉴에 장치별 사용 중 소비전력과 대기전력을 **W(와트)** 단위로 입력합니다. 빈칸은 미설정이며 `0`은 0 W로 저장됩니다.

지원하는 단일 부하 장치에서는 입력한 사양과 확인된 전원 상태로 전력·누적 사용량을 추정해 Matter에 제공합니다. 실제 측정값이 아니며, 상태 미확인·연결 끊김·재시작 공백은 계산에서 제외합니다. 전력 또는 전력량 실측 설정이 있으면 실측을 우선합니다. 적용하려면 플러그인과 해당 브리지에서 Matter를 켜고 저장 후 재시작하세요.

Homebridge의 Matter 콘센트 타일은 W를 표시할 수 있습니다. 조명은 원래 종류를 유지하므로 타일에 W가 보이지 않을 수 있고, Apple Home의 에너지 표시는 운영체제와 컨트롤러 지원에 따라 다릅니다. [소비전력 입력 안내](docs/product-specs/3.0-beta-guide.md#소비전력-사양)와 [실측 설정 안내](docs/product-specs/3.0-beta-guide.md#전력-측정)를 참고하세요.

## 지원 기기와 기능

모델과 기기가 제공하는 값에 따라 지원 범위가 달라집니다. 아래 표는 코드 기준이며, 모든 모델의 실물 검증을 마쳤다는 뜻은 아닙니다.

| 제품군 | 제공 기능과 제한 |
| --- | --- |
| RGB/RGBW 조명·LED 스트립 | 전원·밝기·색상. 지원 장치의 Matter 밝기 조절 |
| 색온도 조명 | 전원·밝기·색온도. Apple Home 적응형 조명 |
| 벽 스위치·릴레이 | 전원, 여러 스위치의 개별 제어 |
| 플러그·멀티탭 | 전원, 개별 콘센트 제어. 보정 설정이 있는 모델의 전력 측정 |
| 커튼·블라인드 | 위치 확인·목표 위치 제어. 정지·각도 조절은 미지원 |
| 모션·문 열림·누수·연기 센서 | 기기가 제공하는 감지·경보 상태 |
| 온습도 센서 | 온도·습도 |
| 공기청정기 | 지원 타입 `Airpurifier`의 전원 제어, 설정 화면에서 모드 변경. 배율을 확인해 설정한 경우 PM2.5 읽기 |
| 지원 도어락 | `ZigbeeDoorlock`의 문 열림만 읽기. 잠금 상태·잠금·해제 조작은 미지원 |

배터리 정보를 제공하는 기기는 배터리 상태도 표시합니다. 실제 장치 타입과 세부 기능은 [장치별 지원 목록](src/devices/capabilities.ts) 및 [베타 사용 안내](docs/product-specs/3.0-beta-guide.md)에서 확인할 수 있습니다.

### 적외선 리모컨 장비

| 제품군 | 제공 기능 |
| --- | --- |
| TV·셋톱박스 | 전원 제어 또는 순간 전원 버튼. 설정 화면의 음량·채널·음소거 조작. 선택 시 Apple Home 리모컨 버튼 6개 |
| 선풍기 | 보고된 전원 상태가 있으면 선풍기 전원 제어, 없으면 순간 전원 버튼. 선택 시 바람 세기·회전 버튼 2개. Matter 연결은 미지원 |
| 에어컨 | 전원 제어. 설정 화면에서 보고된 설정 온도·운전 방식·바람 세기 확인과 변경 |
| 기타 지원 장비 | 확인된 전원 명령 범위 |

에어컨을 제외한 지원 적외선 장비에서 전원 상태값이 없으면 Apple Home에 **한 번 누르는 전원 버튼**으로 표시합니다. 전원 상태값이 있더라도 실물 상태를 별도로 검증한 것은 아닙니다. Matter의 켜기·끄기는 전원 상태값을 제공하는 지원 장치로 제한합니다.

추가 리모컨 버튼은 기본적으로 꺼져 있습니다. 장치별 **리모컨 버튼을 Apple Home에 표시**를 켜고 저장·재시작하면 기존 장치에 추가됩니다. 각 버튼은 명령을 한 번 보내고 다시 꺼집니다. 실제 음소거·풍량·회전 상태를 표시하는 기능은 아니며, 채널 번호 입력은 설정 화면에서 사용합니다.

에어컨의 실제 운전 상태를 확인할 수 없어 Apple Home·Matter의 온도조절기 화면은 제공하지 않습니다. 별도 헤이홈 온도계를 연결하면 설정 화면에서 실제 현재 온도를 함께 확인할 수 있습니다.

### 아직 제공하지 않는 기능

스마트 버튼의 클릭 자동화, 레이더의 지속 재실 감지, 커튼 정지·각도 조절, 미보정 공기질·필터 기능, RGBW 색온도 확장·장면 설정, 카메라 영상·녹화(HKSV), 도어락 잠금·해제는 제공하지 않습니다. 확인되지 않은 기능이나 측정값을 임의로 만들지 않습니다.

Homebridge 관리 화면 6 알파의 자동화 연계는 별도 시험 항목입니다. 사용 전 [자동화 안내](docs/product-specs/smart-automation-guide.md)를 확인하세요.

## 2.x에서 업데이트하기

설정을 백업하고 다음 변경을 확인하세요.

| 변경 사항 | 확인할 내용 |
| --- | --- |
| 실행 환경 | 3.0은 Homebridge 2.4 이상이 필요합니다. Homebridge 1에서는 호환되는 플러그인 2.0·2.1 계열을 사용하세요. |
| 에어컨·스마트 버튼 | 확인되지 않은 운전 상태나 클릭 이벤트를 제공하던 항목이 제거됩니다. 기존 자동화를 점검하세요. |
| 연결 방식·표시 형태 | 기존 장치 식별자는 유지하지만 제공되는 서비스가 달라져 앱 설정이나 자동화 수정이 필요할 수 있습니다. |

문제 해결을 위해 기존 페어링이나 액세서리 정보를 먼저 초기화하지 마세요. [베타 변경 안내](docs/product-specs/3.0-beta-guide.md#이전-버전과-달라지는-표시)를 확인한 뒤 주요 장치와 자동화를 점검하세요.

### 정식 버전으로 돌아가기

새 연결 옵션을 끄고 [복귀 절차](docs/product-specs/3.0-beta-guide.md#정식-버전으로-돌아가기)를 따릅니다. 2.0·2.1 계열로 돌아갈 때는 백업을 남긴 뒤 Hejhome 설정의 `features` 항목을 제거해야 합니다. `@latest`는 설치 시점의 정식 버전이므로 특정 버전으로 돌아가려면 버전 번호를 지정하세요.

## 연결이 안 될 때

먼저 **도움말 → 연결 상태**를 확인하세요.

| 증상 | 확인할 내용 |
| --- | --- |
| 장치 상태는 바뀌는데 조작이 안 됨 | 로그인 만료 여부를 확인하고 다시 로그인합니다. 상태 수신과 제어 인증은 서로 다를 수 있습니다. |
| 새 장치가 보이지 않음 | 자동 검색을 기다린 뒤 집·방 선택, 숨김 설정과 지원 모델을 확인합니다. |
| 같은 장치가 두 개로 보임 | 같은 앱에 Apple Home 연결과 Matter 연결을 모두 추가했는지 확인합니다. |
| 센서값이 표시되지 않음 | 새 측정 보고와 유효 시간을 확인합니다. PM2.5는 확인된 단위에 맞는 배율도 필요합니다. |
| 명령 응답이 늦음 | 실물 동작을 확인한 뒤 다시 조작합니다. 응답이 없다고 명령이 실행되지 않았다고 단정할 수는 없습니다. |
| 집·방 설정 충돌 안내가 나옴 | **최신 설정 불러오기**로 저장된 내용을 확인한 뒤 필요한 변경을 다시 선택합니다. |
| 측정 기능을 끈 뒤 설정 저장이 막힘 | 남아 있는 유효 시간이 표시되면 **유효 시간 지우기**를 누른 뒤 저장합니다. |

**‘명령 전송 완료’는 서버가 요청에 응답했다는 뜻입니다.** 실제 동작은 뒤이어 받은 상태나 실물로 확인해야 합니다.

해결되지 않으면 개인 정보 없는 진단 내용, 설치 버전, 모델, 재현 순서와 발생 시각을 정리해 [문제를 등록해 주세요](https://github.com/chazepps/homebridge-hejhome/issues). 비밀번호·인증번호·토큰·쿠키는 공유하지 마세요.

## 개인정보와 검증

로그인 세션은 `config.json`과 분리해 Homebridge에 보관합니다. 비밀번호와 인증번호는 저장하지 않으며, 개발자에게 진단 내용을 자동 전송하지 않습니다.

장치 연결·재연결, 설정 저장, 명령 순서, 누락된 상태값, 계정 변경과 화면 동작을 자동 테스트로 검증합니다. 자동 테스트 통과와 실물 검증은 구분하며, 남은 확인 사항은 [기능 체크리스트](docs/exec-plans/2026-09-30-homebridge-feature-action-checklist.md)에 기록합니다.

## 개발과 기여

저장소의 `.nvmrc`에 지정된 Node.js 버전을 사용합니다.

```sh
nvm use
npm ci
npm run build
npm run homebridge:dev
```

| 작업 | 명령 |
| --- | --- |
| 개발용 Homebridge 관리 화면 실행 | `npm run homebridge:ui` |
| 설정 화면만 빌드 | `npm run build:ui` |
| 가상 장치로 화면 미리보기 | `npm run preview:ui` — 빌드 후 `http://127.0.0.1:4173`에서 확인 |
| 최초 브라우저 테스트 준비 | `npx playwright install chromium` |
| 코드·화면·문서 전체 검증 | `npm run verify` |
| 배포 패키지 구성 확인 | `npm pack --dry-run` |

개발 설정은 `test/hbConfig/config.json`에 있습니다. 화면 미리보기는 가상 응답을 사용하며 실제 장치를 조작하지 않습니다.

설정 화면은 `homebridge-ui/src/`의 React·Radix UI 코드에서 수정합니다. `homebridge-ui/public/index.html`은 빌드 결과물이므로 직접 편집하지 마세요. `npm run build`에는 화면 빌드도 포함됩니다.

새 장치를 지원할 때는 실제 보고값과 명령의 의미를 확인하고 관련 테스트를 함께 추가해 주세요. 자세한 내용은 [전체 구조](ARCHITECTURE.md), [문서 목록](docs/README.md), [보안 안내](docs/SECURITY.md)를 참고하세요.
